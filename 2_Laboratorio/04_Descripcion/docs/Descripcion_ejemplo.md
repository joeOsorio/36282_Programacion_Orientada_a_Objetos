Continuando el programa del libro:

1.- Haz un archivo Libreria.java

La clase Librería tiene una cantidad de libros disponibles ( 5)
a clase Librería puede registrar libros
La clase Librería puede buscar libros de sus libros disponibles
La clase Librería puede editar libros de sus libros disponibles
La clase Librería puede eliminar libros de sus libros disponibles
La clase Librería puede imprimir información de libros de sus libros disponibles
2.- crea un archivo ProgramaLibreria.java
en este archivo es el programa principal
haz un menu donde tengas las opciones de (registrar, buscar, editar, eliminar) libros en libreria
haz un programa donde muestres todas las funcionalidades de la clase Librería
