# Laboratorio 6: Asociación y Composición pt3

Haz un Un sistema de gestión de consultas de una veterinaria.

- La veterinaria no es el main.
- La veterinaria tiene una lista de doctores (10).
- La veterinaria puede contratar doctores, despedir doctores y suspender doctores (no esta despedido pero no puede tomar acciones en la veterinaria)
- La veterinaria tiene capacidad para registrar 50 mascotas.
- Para poder usar la veterinaria, un doctor se tiene que loguear.
- Una vez que un doctor este logueado puede , dar de alta una mascota, dar de baja una mascota, dar un diagnóstico a una mascota , siempre y cuando no este suspendido.
- Debe de haber un super usuario que permita utilizar las funcionalidades de, registrar, despedir, suspender doctores.
- Doctores tiene Información sensible (personal) e información de trabajo (usuario, clave, no de empleado)
- Las mascotas tienen información sensible (personal y dueño), así como un diagnóstico

Haz un programa donde puedas demostrar todos los puntos anteriores, (registra 3 doctores, y 4 mascotas), prueba cada una de las funcionalidades.
