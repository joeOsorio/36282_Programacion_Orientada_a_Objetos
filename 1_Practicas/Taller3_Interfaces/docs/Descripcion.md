# taller: Interfaces

Haz el diagrama y el código del siguiente problema.

1) Dado una clase número, compone la clase con las siguientes interfaces:
mostrar_binario
mostrar_octal
mostra_hexadecimal
las interfaces no deben llevar parámetros (utiliza los atributos de la clase que las implementa)

2) En vez de una clase número implementa las en una clase texto
( para convertir el texto en otro sistema , tu decides si la suma de su ascii o hashear en un número -> https://cp-algorithms.com/string/string-hashing.html )
