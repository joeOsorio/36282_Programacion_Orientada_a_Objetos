# Practica 7

## Laboratorio

Haz un sistema de banco , donde un usuario puede obtener una cuenta bancaria, con esa cuenta bancaria puede retirar, abonar o eliminar su cuenta en un cajero bancario, ten en cuenta que el banco no es el main.

Para poder usar el cajero debes acceder a las cuentas almacenadas en el banco, el pin debe coincidir con el pin del usuario.
Una vez dentro del cajero puede hacer las operaciones mencionadas.

Solo 1 usuario a la vez puede usar el cajero.

El banco puede abrir cuenta, cerrar cuenta al usuario .

Haz un programa donde pruebes todas las funcionalidades.

   Fragmento de código de los métodos que resuelven el problema.
   Imagen de esas funciones ejecutadas
   Explicación (con sus palabras) de porque lo codifico así
3. Reflexión y análisis crítico
   Dificultades técnicas
   Fracasos, fallas, bugs, errores
   Como resolvió lo anterior con sus palabras.
   Conclusión (con sus palabras)
