# 📘 Programación Orientada a Objetos

Repositorio académico de la materia **Programación Orientada a Objetos** (clave 36282, grupo 541) de la carrera de **Ingeniería en Computación**, Facultad de Ciencias Químicas e Ingeniería, UABC. Semestre 2026-2.

**Docente:** Gustavo Omar Zamarrón de la Garza

## 🎯 Objetivo
Aplicar los principios de la programación orientada a objetos (abstracción, encapsulamiento, herencia, polimorfismo, persistencia y concurrencia) mediante talleres, laboratorios y un proyecto final en Java.

## 🗂️ Unidades del curso
1. **Abstracción y Encapsulamiento** — Clases, objetos, niveles de acceso, manejo de métodos (semanas 1-2)
2. **Modularidad y Jerarquía** — Herencia, herencia múltiple, composición, paquetes (semanas 3-6)
3. **Polimorfismo y Reutilización de código** — Polimorfismo, cohesión, acoplamiento (semanas 7-10)
4. **Persistencia y Concurrencia** — Persistencia (archivos), concurrencia (hilos) (semanas 11-13)
5. **Proyecto** — Tiempo libre para el desarrollo del proyecto final (semanas 14-17)

## 🏗️ Proyecto final
Programa en Java que implemente herencia, interfaces, polimorfismo y clases abstractas (e hilos/serialización si se alcanza a cubrir), con estructura de folders modular: un folder para el código fuente, uno para el ejecutable y un archivo por clase.

## 🛠️ Tecnologías
- Lenguaje: Java (JDK XX)
- Estándares de codificación: Java Code Conventions / ANSI C
- Control de versiones: Git y GitHub
